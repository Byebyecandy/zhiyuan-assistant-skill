# Advisor Modules Research Notes

> Collected: 2026-06-10
> Scope: Publicly available profile clues and content patterns. This file is a short evidence map, not a biography database.

## Method

The skill abstracts public communication methods into neutral planning modules. It does not claim to reproduce any person's private thinking, endorsement, voice, likeness, or exact expression.

## Modules

### Reality-Check Module

Observed pattern:
- Direct first conclusion.
- Employment-outcome framing.
- Family background and cost sensitivity.
- Strong warning against low-return choices.

Usable abstraction:
- `就业倒推 + 家庭成本 + 学历门槛`.

Do not:
- Use insults, exact catchphrases, or fake first-person identity.

### Full-Chain Planning Module

Observed pattern:
- Treat升学 as a long chain from小初高 to本科/硕博/就业.
- Emphasize staged path design.
- Encourage families to see current choices as part of a longer route.

Usable abstraction:
- `当前阶段 + 3个月动作 + 1年动作 + 3-7年路径`.

Do not:
- Replace concrete student data with broad slogans.

### Rule-Debugging Module

Observed pattern:
- Short-form explanation of投档、调剂、批次、特殊招生 and专业出口.
- Useful for parents who are confused by policy terms.

Usable abstraction:
- `定义 - 影响 - 误区 - 操作建议 - 核验清单`.

Do not:
- Generalize one province's rule to every province.

### School-Major Fit Module

Observed pattern:
- Single-school and single-major explanation.
- Focus on学校层次、学科、城市、就业、适合人群.

Usable abstraction:
- `学校画像 + 专业画像 + 学生适配`.

Do not:
- Infer private credentials or treat same-name accounts as confirmed.

### Local-Career Module

Observed pattern:
- Province-specific policy explanation.
- Combines志愿梯度 with职业规划 and employer expectations.

Usable abstraction:
- `本省规则 + 职业出口 + 冲稳保 + 风险清单`.

Do not:
- Make success-rate or录取承诺 claims.

## Source Types Used

## Evidence Quality

- Some public figures have multiple independently verifiable sources.
- Some names have only article-level or search-result-level clues; treat those modules as lower-confidence abstractions.
- The public GitHub release should avoid framing this as a definitive profile of five specific living people.
